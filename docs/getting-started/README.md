# Getting Started

Pixelay is a user interface engine for Minecraft Paper 1.21+ servers. It uses principles from HTML and CSS.
Developers can build responsive, multi-layered interfaces with pixel precision.
Pixelay renders interfaces in the 3D game world or as full-screen interactive sessions.

## Key Capabilities

- **Flexible Canvas**: A rotatable pixel plane of any width and height.
- **Rich Components**: Text, buttons, toggles, checkboxes, progress bars, 2D drawing canvas, and 3D models.
- **Rendering Modes**: Server entities, per-player entities, or packet-only entities.
- **CSS Layout Engine**: Box model, flexbox rows and columns, CSS Grid, stacks, and absolute positioning.
- **Font Measurement**: Automatic glyph width measurement from vanilla and custom resource packs.
- **Dynamic Content**: Live suppliers and PlaceholderAPI with automatic refresh timers.
- **Screen Sessions**: Full-screen spectator sessions with zero-latency core shader cursors.
