# Layout Engine

Pixelay implements a declarative layout engine based on HTML and CSS.

## Section Overview

- [Layout Lifecycle & Refreshing](layout-lifecycle-and-refreshing.md) — Understand layout measurement, dynamic suppliers, and `refresh()`.
- [Box Model](box-model.md) — Sizing, min and max dimensions, borders, padding, margins, opacity, and clipping.
- [Flexbox Layouts](flexbox-layouts.md) — Horizontal rows, vertical columns, flex growth, flex shrink, alignment, and justification.
- [CSS Grid System](css-grid-system.md) — Grid definitions, fixed pixel tracks, fractional `fr` tracks, track repeat, and cell spans.
- [Positioning & Offsets](positioning-and-offsets.md) — Static, relative, and absolute positioning with pixel edge anchors.
- [Scrolling & Stack Containers](scrolling-and-stack-containers.md) — Smooth scroll views with dragging support and overlapping stack containers.
