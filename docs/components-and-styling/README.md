# UI Components

Pixelay includes built-in component primitives for text, user input, drawing, and 3D rendering. All components inherit from `Box<S>`.

## Section Overview

- [Typography & Text Metrics](typography-and-text-metrics.md) — MiniMessage formatting, pixel font measurements, line wrapping, and ellipsis truncation.
- [Buttons & Click Listeners](buttons-and-click-listeners.md) — Interactive buttons, click handlers, debounce timing, and pointer cursors.
- [Form Controls & Progress Bars](form-controls-and-progress-bars.md) — Checkboxes, toggle switches, and progress bar indicators.
- [2D Drawing Canvas](2d-drawing-canvas.md) — Programmatic drawing API, player brush painting, and 2D greedy meshing.
- [3D Item & Block Displays](3d-item-and-block-displays.md) — Rendering 3D Minecraft ItemDisplay and BlockDisplay models inside 2D layouts.
