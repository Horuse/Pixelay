# Web Editor Specification

Pixelay provides a complete read and write Document Object Model (DOM) introspection API and a canonical JSON document format.
External visual web editors, visual designers, and automated tools can inspect and manipulate live layouts.

## Section Overview

- [DOM Introspection & Mutation API](dom-introspection-and-mutation-api.md) — Accessors, mutators, and child node manipulation for live `MountedLayout` instances.
- [JSON Document Schema](json-document-schema.md) — Schema definitions for exporting and importing complete layouts as JSON.
